# ETL Report

## Исходные файлы

* `import_partners.csv`
* `import_sales.txt`

## Обнаруженные аномалии

1. В `company_name` у партнеров с `partner_id = 1` и `partner_id = 3` присутствовали лишние пробелы по краям. Пробелы были удалены.

2. У продажи `sale_id = 102` дата была записана в формате `15.03.2026`. Дата была приведена к единому формату `2026-03-15`.

3. Продажа `sale_id = 104` ссылается на `partner_id = 4`, которого нет в файле партнеров. Запись была исключена из подготовленных данных для импорта.

4. Дубликатов записей и повторяющихся идентификаторов `partner_id` и `sale_id` не обнаружено.

5. Повторяющихся значений ИНН и email партнеров не обнаружено.

6. У партнера с `partner_id = 2` отсутствует `phone`, а у партнера с `partner_id = 3` отсутствует `rating`. Поскольку эти поля допускают `NULL`, отсутствующие значения были сохранены как `NULL`.

## Подготовка данных

После очистки исходных файлов были подготовлены три файла для импорта:

* `prepared_partners.csv` — очищенные данные партнеров;
* `prepared_products.csv` — справочник уникальных товаров;
* `prepared_sales.csv` — подготовленная история продаж.

В исходном файле `import_sales.txt` товары были представлены полем `product_name`.

Для соблюдения 3NF из уникальных названий товаров был сформирован отдельный справочник `products`. Каждому товару был присвоен `product_id`.

В подготовленном файле продаж поле:

```text
product_name
```

было заменено на:

```text
product_id
```

Таким образом, таблица `sales` содержит ссылку на товар через внешний ключ и не дублирует его название.

## Результат очистки

* партнеров после очистки: **3**;
* уникальных товаров: **3**;
* корректных продаж для импорта: **4**;
* исключенных продаж: **1**.

Из импорта исключена запись:

```text
sale_id = 104
partner_id = 4
```

Причина: партнер с `partner_id = 4` отсутствует в исходном файле партнеров.

## Импорт данных

Подготовленные данные импортируются в следующие таблицы:

```text

        ↓
partners

prepared_products.csv
        ↓
products

prepared_sales.csv
        ↓
sales
```

Импорт выполняется средствами PostgreSQL с использованием команды `\copy`.
